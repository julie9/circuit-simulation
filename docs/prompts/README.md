# AI Work Log

This directory records how AI assistance was used while developing the circuit simulator. The goal is to preserve project context, decisions, and lessons learned, not to create a library of reusable prompts.

## How to record a session

Add a new entry at the top of this file after a meaningful coding session. Use the date and a short description as the heading.

## Entry format

### YYYY-MM-DD: Short description

**Prompt**

What was asked of the AI?

**Result**

What changed or was investigated?

**Notes**

Important decisions, tests, lessons, or follow-up work.
